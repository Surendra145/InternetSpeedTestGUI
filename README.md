# 🌐 **Internet Speed Test GUI**

## 📖 **Project Description**

**Internet Speed Test GUI** is a simple Python application that allows users to check their internet connection speed in real-time through a **graphical user interface (GUI)**. It uses the **speedtest-cli** library to measure key metrics like **download speed**, **upload speed**, and **ping**.

The results are displayed in a user-friendly window built with **Tkinter**, making it accessible even for those who are not comfortable using command-line tools. This application is ideal for anyone who wants to quickly assess their internet connection’s performance without needing to visit a website or run complex commands.

### Features:
- Measure **download speed** and **upload speed**.
- View **ping** results to check connection stability.
- **User-friendly GUI** with simple controls.
- **Instant results** with a button click.

---

## 🔧 **Tech Stack**

- **Python**:  
  The core programming language used to build this project. It's simple, versatile, and well-suited for scripting and GUI-based applications.
  
- **Tkinter**:  
  A standard Python library used to create the graphical user interface (GUI). Tkinter allows you to design windows and display the results in a clean format.

- **speedtest-cli**:  
  A Python library that connects to Speedtest.net to fetch internet speed data (download speed, upload speed, and ping).

- **Git**:  
  Version control system used for managing and tracking the project’s code changes.

- **GitHub**:  
  Platform used to host and share the project’s source code.
